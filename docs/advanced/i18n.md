# 国际化文本

组件内置的下拉刷新、加载更多、空数据文案默认支持简体中文（`zh-Hans`）、繁体中文（`zh-Hant`）和英文（`en`），并可运行时切换。

## 默认行为

不传任何文案 Prop 时，组件内置文案按当前语言渲染：

- 默认 `auto`：读取 `wx.getAppBaseInfo().language`，`zh_CN` 归为 `zh-Hans`，`zh_TW` / `zh_HK` 归为 `zh-Hant`，其余英文环境归为 `en`，无法识别时回退 `zh-Hans`。
- 非微信测试环境读不到系统语言时，同样回退 `zh-Hans`。

## 运行时切换

微信没有 `uni.setLocale`，系统语言在运行期不可修改；组件提供应用内的语言切换：

```ts
// 跟随系统（默认）
paging.setLocale('auto')
// 指定英文
paging.setLocale('en')
// 读取当前实际使用的语言
paging.getLocale()
```

切换后，下拉刷新、加载更多、空数据等**内置文案**立即重新渲染。页面自身文案不在组件管辖范围内，需要业务自行处理。

## 单条文案覆盖

文案 Prop 支持两种写法：

- 字符串：固定使用该文案。
- 多语言对象：按当前语言取，取不到依次回退 `zh-Hans`、`en`、对象首个值。

```vue
<ZPagingWevu
  :refresher-default-text="{
    'zh-Hans': '继续下拉刷新',
    en: 'Pull down to refresh',
  }"
  :loading-more-no-more-text="{
    'zh-Hans': '没有更多了',
    en: 'No more data',
  }"
/>
```

## 支持多语言文本的主要 Props

- `refresher-default-text`
- `refresher-pulling-text`
- `refresher-refreshing-text`
- `refresher-complete-text`
- `loading-more-default-text`
- `loading-more-loading-text`
- `loading-more-no-more-text`
- `loading-more-fail-text`
- `empty-view-text`
- `empty-view-reload-text`
- `empty-view-error-text`

类型定义为：

```ts
type ZPagingWevuText = string | Record<string, string>
```

若业务已有完整 i18n 方案，也可以先由业务层翻译，再把普通字符串传给组件。
